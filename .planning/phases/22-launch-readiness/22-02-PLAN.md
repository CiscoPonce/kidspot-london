    **1. Create `frontend/public/sw.js`:**

    Implement a manual service worker with versioned cache names. The structure from RESEARCH.md §300-337 is the reference pattern, with these specific additions:

    - Cache name constants: `CACHE = 'kidspot-v1'`, `SEARCH_CACHE = 'kidspot-search-v1'`, `DETAIL_CACHE = 'kidspot-detail-v1'`, `STATIC_CACHE = 'kidspot-static-v1'`
    - `install` event: pre-cache app shell `['/', '/manifest.json', '/icon-192x192.png', '/icon-512x512.png']` into STATIC_CACHE
    - `activate` event: delete old caches (any key not matching current version names), then call `self.clients.claim()`
    - `fetch` event routing:
      - Search API (`/api/search/venues`): `networkFirst()` — try network, fall back to cache

      - Static assets (JS, CSS, images in `/`): `cacheFirst()` — serve from cache, update on new version
      - Navigation requests (HTML pages): `networkFirst()` with fallback to cached app shell
    - Helper functions `networkFirst(request, cacheName)`, `staleWhileRevalidate(request, cacheName)`, `cacheFirst(request, cacheName)` using the Cache API
    - `message` event listener: listen for 'skip-waiting' message to call `self.skipWaiting()` (for update prompt)

       ```tsx
               });
       ```


    **Part B — Update `frontend/next.config.js`:**

    Add an `async headers()` method to the existing config (before `module.exports`):

    ```javascript
    async headers() {
      return [
        {
          source: '/sw.js',
          headers: [
            { key: 'Content-Type', value: 'application/javascript; charset=utf-8' },
            { key: 'Cache-Control', value: 'no-cache, no-store, must-revalidate' },
            { key: 'Service-Worker-Allowed', value: '/' },
          ],
        },
        {
          source: '/(.*)',
          headers: [
            { key: 'X-Content-Type-Options', value: 'nosniff' },
            { key: 'X-Frame-Options', value: 'DENY' },
            { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
          ],
        },
      ];
    }
    ```
    - The `no-cache, no-store, must-revalidate` on `/sw.js` prevents the SW from being cached (Pitfall 1 mitigation per RESEARCH.md §369)
    - The global security headers (X-Content-Type-Options, X-Frame-Options, Referrer-Policy) add defense-in-depth
