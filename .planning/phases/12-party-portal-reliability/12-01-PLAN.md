| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-12-01 | Tampering | editor_locked field | mitigate | Database-level constraint prevents direct UPDATE without proper authorization; admin-only API endpoint for setting editor_locked |
| T-12-02 | Spoofing | provenance_log.changed_by | mitigate | Use system-generated identifiers for batch jobs; validate user tokens for manual changes; log IP addresses |
| T-12-03 | Information Disclosure | venue_provenance_log | accept | Provenance data is non-sensitive (field changes, timestamps); no PII stored; public read access acceptable for transparency |
| T-12-04 | Elevation of Privilege | cron-agent bypassing guardrails | mitigate | Database trigger enforces logging; cron agent runs with limited database permissions; no direct table access |
| T-12-05 | Repudiation | venue data changes | mitigate | All changes logged with source, changed_by, timestamp, and reason; immutable audit trail via append-only log table |
