# Plan 09-02: Stripe Integration

## Objective
Implement recurring revenue through Stripe subscriptions for Gold, Silver, and Bronze sponsorship tiers.

## Architectural Changes

### 1. Stripe Product Model
Define three products in the Stripe Dashboard with monthly and yearly pricing:
- **Bronze**: Top 10 placement, subtle badge.
- **Silver**: Top 5 placement, prominent badge, priority support.
- **Gold**: Top 3 placement, featured styling, custom branding.

### 2. Backend Routes
- `POST /api/billing/create-checkout-session`: Creates a Stripe Checkout session for a specific venue and tier.
- `POST /api/billing/webhook`: Handles Stripe webhooks (e.g., `checkout.session.completed`, `customer.subscription.deleted`).
- `GET /api/billing/config`: Returns public Stripe configuration (Publishable Key).

### 3. Frontend Components
- **Pricing Table**: `/claim/[slug]/pricing` — Display tiers and features.
- **Billing Portal**: Integration with Stripe Customer Portal for subscription management.
- **Success/Cancel Pages**: `/billing/success` and `/billing/cancel`.

## Implementation Steps

### Phase A: Setup & Config (Backend)
- [ ] Install `stripe` package in backend.
- [ ] Configure `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` in `.env`.
- [ ] Implement `stripeClient.ts`.

### Phase B: Checkout Flow (Backend)
- [ ] Create `billingController.ts` for checkout session logic.
- [ ] Implement `POST /api/billing/create-checkout-session`.
- [ ] Add security check: User must have a `verified` claim for the venue to create a session.

### Phase C: Webhook Integration (Backend)
- [ ] Implement `billingWebhookHandler.ts`.
- [ ] Map Stripe events to DB updates (update `sponsor_tier`, `stripe_subscription_id`).
- [ ] Add idempotent processing for webhook events.

### Phase D: UI Integration (Frontend)
- [ ] Build pricing selection UI.
- [ ] Integrate Stripe.js for redirection to Checkout.
- [ ] Add "Manage Subscription" button for verified owners.

## Verification Plan
1. **Webhook Test**: Use Stripe CLI to trigger `checkout.session.completed` -> verify DB update.
2. **End-to-End Test**: Simulate claim -> approve -> select tier -> complete test payment -> verify "Gold" badge appears on venue.
3. **Cancellation Test**: Cancel subscription in Stripe -> verify venue tier reverts to `null` in DB.
