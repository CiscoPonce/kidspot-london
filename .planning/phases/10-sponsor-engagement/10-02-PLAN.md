# Plan 10-02: Featured Ranking & Premium UI

## Objective
Ensure sponsors receive maximum visibility through prioritized search rankings and enhanced visual presentation in the search results.

## Architectural Changes

### 1. Ranking Algorithm Fine-Tuning
- Update `search_venues_by_radius` to ensure Gold sponsors are always boosted to the top regardless of exact distance (within a reasonable threshold).
- Implement a "Sponsor Rotation" logic to prevent the same Gold sponsor from dominating the top spot if multiple exist in the same area.

### 2. Premium Venue Cards
- **Gold Tier**: Larger card, background color highlight, "Featured" label, additional photos carousel.
- **Silver Tier**: Highlighted border, "Verified" badge, up to 3 photos.
- **Bronze Tier**: Standard card with "Sponsor" badge.

### 3. Global Featured Section
- Add a "Featured Places" section to the homepage that displays 3 random Gold sponsors from across London.

## Implementation Steps

### Phase A: Sorting Logic (Backend)
- [ ] Refine `ORDER BY` clause in SQL functions to incorporate random tie-breaking for same-tier sponsors.
- [ ] Add `is_featured` boolean to the API response for easier frontend targeting.

### Phase B: Enhanced Components (Frontend)
- [ ] Update `VenueCard.tsx` with conditional styles for `sponsor_tier`.
- [ ] Implement `PhotoCarousel` for premium cards.
- [ ] Add `FeaturedHero` component to the homepage.

### Phase C: Search API Enhancements (Backend)
- [ ] Ensure `searchVenues` correctly handles multi-tier sorting for all search types (borough, radius, global).

## Verification Plan
1. **Ranking Test**: Perform a search in an area with a Gold sponsor -> verify they appear at position #1 even if an organic result is slightly closer.
2. **Visual Test**: Verify that Gold, Silver, and Bronze cards have distinct visual hierarchies.
3. **Rotation Test**: Refresh search multiple times -> verify that tie-breaking rotation works for same-tier sponsors.
