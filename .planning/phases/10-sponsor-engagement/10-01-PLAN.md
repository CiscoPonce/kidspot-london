# Plan 10-01: Sponsor Dashboard & Analytics

## Objective
Provide verified venue owners with a private portal to view their lead generation performance (clicks, views) and manage their listing details.

## Architectural Changes

### 1. Owner Authentication
- Implement a lightweight "Owner Login" using the `claim_email` and a one-time-passcode (OTP) sent via email.
- Store sessions in Redis or use JWTs.

### 2. Analytics Engine
- Create `GET /api/owner/stats` endpoint.
- Aggregates `outbound_clicks` for the owner's specific venue.
- Add `venue_views` tracking to `GET /api/search/venues/:id/details` to calculate conversion rates (CTR).

### 3. Management API
- `PATCH /api/owner/venue`: Allow owners to update `description`, `website`, `phone`, and `features`.
- `POST /api/owner/photos`: Allow owners to upload/manage photos (Sponsors only).

### 4. Frontend Dashboard
- `/owner/dashboard`: Overview of stats.
- `/owner/edit-listing`: Form to update venue details.
- `/owner/billing`: Link to Stripe Customer Portal.
