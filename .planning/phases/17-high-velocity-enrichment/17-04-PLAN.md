# Plan 17-04: Rich Data Schema Upgrades

## Objective
Update the database schema and application layers to store and display the rich metadata (opening hours and hero images) provided by the Apify integration.

## Proposed Changes

### 1. Database Migration
- **Location:** `backend/db/migrations/022_add_rich_venue_data.sql`
- **Functionality:**
  - Add `opening_hours` column of type `JSONB` to the `venues` table.
  - Add `images` column of type `TEXT[]` to the `venues` table.
- **Migration Script:** Create `backend/run-migration-022.js` to execute the SQL safely.

### 2. API Updates
- **Location:** `backend/src/routes/venues.ts` (or relevant controller)
- **Functionality:**
  - Ensure the new `opening_hours` and `images` columns are selected in the venue detail endpoint (`GET /api/venues/:id`).
  - Update any TypeScript interfaces/types (`backend/src/types/index.ts`) to reflect the new optional fields.

### 3. Frontend UI Integration
- **Location:** `frontend/src/app/venues/[slug]/page.tsx` (and related components)
- **Functionality:**
  - **Images:** If the `images` array exists and has items, display the first image as the hero banner or in a carousel instead of the default placeholder.
  - **Opening Hours:** Create a small "Opening Hours" collapsible card or list in the sidebar of the venue detail page to render the JSONB data (e.g., `Monday: 9:00 AM - 5:00 PM`).

---

## Technical Details

### JSONB Structure (Opening Hours)
Apify returns hours in an array. We will store it exactly as returned for easy frontend parsing:
```json
[
  { "day": "Monday", "hours": "9 AM - 5 PM" },
  { "day": "Tuesday", "hours": "Closed" }
]
```

### Data Mapping in `apify-enrichment.ts`
Update the mapping logic to extract these fields:
```typescript
const openingHours = item.openingHours ? JSON.stringify(item.openingHours) : null;
const images = item.imageUrls ? item.imageUrls.slice(0, 3) : null; // Take top 3
```

## Verification Plan
1.  **Migration Test:** Run the migration and verify the columns exist in `psql`.
2.  **API Check:** Call the venue detail API for an enriched venue and ensure `opening_hours` and `images` are returned.
3.  **UI Check:** Load the venue detail page in the browser and verify the hero image and hours render correctly without breaking the layout.
