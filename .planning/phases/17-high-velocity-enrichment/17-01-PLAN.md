# Plan 17-01: Apify Actor Integration

## Objective
Implement a robust, highly accurate enrichment script using the Apify Google Maps Scraper (`compass~crawler-google-places`) to extract verified contact information for high-value venues.

## Proposed Changes

### 1. New Script: `apify-enrichment.ts`
- **Location:** `backend/scripts/discovery/sources/apify-enrichment.ts`
- **Functionality:**
  - Query the database for up to 20 high-value venues (softplay, leisure_centre, museum, library) that are currently missing a `website` or `phone`.
  - Construct precise search strings (e.g., "Science Museum London UK").
  - Trigger a single batch run of the Apify Actor via the REST API (`POST /v2/acts/compass~crawler-google-places/runs`).
  - Poll the Apify API until the run completes.
  - Fetch the resulting dataset.
  - Map the results back to the original venues and update the database.

### 2. Data Mapping
- The script will map the following fields from the Apify payload:
  - `item.website` -> `venues.website`
  - `item.phone` -> `venues.phone` (with basic whitespace removal)
  - `item.totalScore` -> `venues.rating`
  - `item.reviewsCount` -> `venues.user_ratings_total`

---

## Technical Details

### API Request Configuration
```json
{
  "searchStringsArray": ["Venue A London UK", "Venue B London UK"],
  "maxCrawledPlacesPerSearch": 1, 
  "language": "en",
  "countryCode": "gb"
}
```

### Dependency Updates
- No new NPM packages are required. The script will use the native Node 22 `fetch` API.

## Verification Plan
1.  **Unit/Manual Test:** Run `test-apify-batch.ts` to ensure the Actor responds correctly with the expected JSON structure.
2.  **Dry Run:** Execute the enrichment script in dry-run mode to verify the database query accurately selects venues missing contact info.
3.  **Live Run:** Execute the script and verify that the database fields are correctly updated and the `contact_enriched_at` timestamp is set.
